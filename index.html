            Client-Side Rendering (CSR)

            Client-Side Rendering me webpage ka content browser (client side) par JavaScript ki help se render hota hai।

            Server pehle ek basic HTML file bhejta hai, phir browser JavaScript run karke poora page banata hai।

            *  JavaScript data load karke page me content dikhata hai।
            *    Flow
                        Browser Request
                            ↓
                        Server HTML + JS bhejta hai
                            ↓
                        Browser JS run karta hai
                            ↓
                        Page Render hota hai

            First load slow ho sakta hai
            SEO comparatively weak

            Server-Side Rendering (SSR)

            Server-Side Rendering me webpage ka poora HTML server par generate hota hai aur browser ko ready-made page bheja jata hai।

            Browser ko JavaScript ka wait nahi karna padta।

            *  Flow
                    Browser Request
                        ↓
                    Server HTML Generate karta hai
                        ↓
                    Ready HTML Browser ko bhejta hai
                        ↓
                    Page Direct Show hota hai

                SEO friendly

            Disadvantages--:

                Server load badhta hai
                Har request par page generate hota hai

                                1. Arithmetic Operators--:
                                Arithmetic Operators गणितीय (Mathematical) Calculation करने के लिए उपयोग किए जाते हैं।

                                Addition Operator (+)
                                दो या अधिक Numbers को जोड़ने के लिए उपयोग किया जाता है।
                                document.write(10 + 20);
                                30

                                एक Number से दूसरे Number को घटाने के लिए उपयोग किया जाता है।
                                document.write(20 - 10);
                                10

                                Multiplication Operator (*)
                                दो Numbers का गुणा करने के लिए उपयोग किया जाता है।
                                document.write(10 * 5);
                                50

                                एक Number को दूसरे Number से भाग देने के लिए उपयोग किया जाता है।
                                document.write(20 / 5);
                                4

                                Modulus Operator (%)

                                document.write(10 % 3);
                                1

                                Increment Operator (++)
                                Variable की Value में 1 जोड़ता है।
                                let x = 10;
                                x++;
                                document.write(x);
                                11

                                Decrement Operator (--)
                                Variable की Value में 1 घटाता है।
                                let x = 10;
                                x--;
                                document.write(x);

                                document.write(10 === "10");
                                false

                                दो Values बराबर नहीं हैं या नहीं Check करता है।
                                document.write(10 != 20);

                                document.write(10 !== "10");

                                    Greater Than or Equal To (>=)

                                            Use:जब केवल True Condition पर काम करना हो।

                                            2. if...else Statement

                                            जब Condition True हो तो एक Code और False हो तो दूसरा Code Execute करना हो तब if...else का उपयोग करते
                                            हैं।

                                            Syntax
                                            if(condition)
                                            {
                                            // true block
                                            }
                                            else
                                            {
                                            // false block
                                            }
                                            Example
                                            let age = 16;
                                            if(age >= 18)
                                            {
                                            document.write("Eligible");
                                            }
                                            else
                                            {
                                            document.write("Not Eligible");
                                            }
                                            Output
                                            Not Eligible

                                            Use :जब दो option (True/False) हों।

                                            3. else if Ladder
                                            जब कई Conditions Check करनी हों तब else if Ladder का उपयोग किया जाता है।

                                            Syntax
                                            if(condition1)
                                            {
                                            }
                                            else if(condition2)
                                            {
                                            }
                                            else if(condition3)
                                            {
                                            }
                                            else
                                            {
                                            }
                                            Example
                                            let marks = 75;

                                            if(marks >= 90)
                                            {
                                            document.write("Grade A");
                                            }
                                            else if(marks >= 80)
                                            {
                                            document.write("Grade B");
                                            }
                                            else if(marks >= 70)
                                            {
                                            document.write("Grade C");
                                            }
                                            else
                                            {
                                            document.write("Fail");
                                            }
                                            Output
                                            Grade C

                                            Use :जब Multiple Conditions हों।

                                            4. Nested if
                                            जब एक if के अंदर दूसरा if लिखा जाता है तो उसे Nested if कहते हैं।

                                            Syntax
                                            if(condition1)
                                            {

                                            if(condition2)
                                            {

                                            }
                                            }
                                            Example
                                            let feePaid = true;
                                            let parentPermission = true;

                                            if(feePaid)
                                            {
                                            if(parentPermission)
                                            {
                                            document.write("Picnic Allowed");
                                            }
                                            else
                                            {
                                            document.write("Parent Permission Required");
                                            }
                                            }
                                            else
                                            {
                                            document.write("Fee Not Paid");
                                            }

                                            Use: जब एक Condition के अंदर दूसरी Condition Check करनी हो।

                                            5. switch Statement
                                            जब एक Variable की Value के आधार पर कई Cases में से एक चुनना हो तब switch Statement का उपयोग करते हैं।

                                            Syntax
                                            switch(expression)
                                            {
                                            case value1:
                                            code;
                                            break;

                                            case value2:
                                            code;
                                            break;

                                            default:
                                            code;
                                            }
                                            Example
                                            let day = 3;

                                            switch(day)
                                            {
                                            case 1:
                                            document.write("Monday");
                                            break;

                                            case 2:
                                            document.write("Tuesday");
                                            break;

                                            case 3:
                                            document.write("Wednesday");
                                            break;

                                            default:
                                            document.write("Invalid Day");
                                            }
                                            Output
                                            Wednesday

                                            Use: जब एक Variable की कई Fixed Values Check करनी हों।

                                            if(condition and value check)
                                            switch(range and value check fast readable)

                                            one liner:

                                            if Statement
                                            Condition True होने पर Code Execute करने वाला Statement।

                                            if...else Statement

                                            True और False दोनों Conditions के लिए अलग-अलग Code Execute करने वाला Statement।

                                            else if Ladder

                                            Multiple Conditions Check करने वाला Statement।

                                            Nested if

                                            एक if Statement के अंदर दूसरा if Statement।
                                            switch Statement
                                            किसी Expression की Value के आधार पर विभिन्न Cases में से एक को Execute करने वाला Statement।
