JavaScript में मुख्य रूप से 8 प्रकार के Operators होते हैं: Arithmetic Operators Comparison Operators Logical Operators Assignment Operators Bitwise Operators Conditional (Ternary) Operator typeof Operator Special Operators (in, instanceof) JavaScript Conditional Statements:- Conditional Statement वह Statement होता है जो किसी Condition (शर्त) को Check करके निर्णय (Decision) लेता है कि कौन सा Code Execute होगा "अगर Condition सही (true) है तो एक काम करो, नहीं तो दूसरा काम करो।" Age 18 से ज्यादा है या नहीं Student Pass है या Fail Login Successful है या नहीं Week का कौन सा Day है JavaScript में मुख्य रूप से 5 प्रकार के Conditional Statements होते हैं: if Statement if...else Statement if....else if Ladder Nested if switch Statement 1. if Statement जब केवल Condition True होने पर Code Execute करना हो तब if Statement का उपयोग करते हैं। Syntax if(condition) { // code } Example let age = 20; if(age >= 18) { document.write("Eligible for Voting"); } Output Eligible for Voting Use:जब केवल True Condition पर काम करना हो। 2. if...else Statement जब Condition True हो तो एक Code और False हो तो दूसरा Code Execute करना हो तब if...else का उपयोग करते हैं। Syntax if(condition) { // true block } else { // false block } Example let age = 16; if(age >= 18) { document.write("Eligible"); } else { document.write("Not Eligible"); } Output Not Eligible Use :जब दो option (True/False) हों। 3. else if Ladder जब कई Conditions Check करनी हों तब else if Ladder का उपयोग किया जाता है। Syntax if(condition1) { } else if(condition2) { } else if(condition3) { } else { } Example let marks = 75; if(marks >= 90) { document.write("Grade A"); } else if(marks >= 80) { document.write("Grade B"); } else if(marks >= 70) { document.write("Grade C"); } else { document.write("Fail"); } Output Grade C Use :जब Multiple Conditions हों। 4. Nested if जब एक if के अंदर दूसरा if लिखा जाता है तो उसे Nested if कहते हैं। Syntax if(condition1) { if(condition2) { } } Example let feePaid = true; let parentPermission = true; if(feePaid) { if(parentPermission) { document.write("Picnic Allowed"); } else { document.write("Parent Permission Required"); } } else { document.write("Fee Not Paid"); } Use: जब एक Condition के अंदर दूसरी Condition Check करनी हो। 5. switch Statement जब एक Variable की Value के आधार पर कई Cases में से एक चुनना हो तब switch Statement का उपयोग करते हैं। Syntax switch(expression) { case value1: code; break; case value2: code; break; default: code; } Example let day = 3; switch(day) { case 1: document.write("Monday"); break; case 2: document.write("Tuesday"); break; case 3: document.write("Wednesday"); break; default: document.write("Invalid Day"); } Output Wednesday Use: जब एक Variable की कई Fixed Values Check करनी हों। if(condition and value check) switch(range and value check fast readable) one liner: if Statement Condition True होने पर Code Execute करने वाला Statement। if...else Statement True और False दोनों Conditions के लिए अलग-अलग Code Execute करने वाला Statement। else if Ladder Multiple Conditions Check करने वाला Statement। Nested if एक if Statement के अंदर दूसरा if Statement। switch Statement किसी Expression की Value के आधार पर विभिन्न Cases में से एक को Execute करने वाला Statement।
